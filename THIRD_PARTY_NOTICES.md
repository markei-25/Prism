## PyBox Snake game

Prism's embedded Snake game adapts the Snake gameplay from PyBox:

- Repository: <https://github.com/hhhrrrttt222111/PyBox>
- Original game: <https://github.com/hhhrrrttt222111/PyBox/blob/master/Games/Snake.py>
- Copyright (c) 2021 Hemanth R
- License: MIT

The original game uses Python's `turtle` module and `freegames` helpers. Prism adapts its grid movement, food collection, growth, and collision rules to a PyQt widget so it can run inside the application.
